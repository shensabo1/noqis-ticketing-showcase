# NoQis Support Desk: Project Showcase

A one-page visual summary of the first clickable version of the NoQis Support Desk, the email-driven ticketing system
for NoQis CDN support.

Open `index.html` in a browser. It shows:

- The agent console screens: ticket list, ticket page, and new-ticket form (`screenshots/`)
- What happens when an agent saves a change, and how the audit hash chain links entries
- The rules the system enforces and where each one is tested
- Progress against the project roadmap
- How to run the app and a walkthrough checklist

The application code lives in [noqis-ticketing-system](https://github.com/shensabo1/noqis-ticketing-system)
([pull request #1](https://github.com/shensabo1/noqis-ticketing-system/pull/1)).

All organizations, people, and tickets shown are invented sample data.
