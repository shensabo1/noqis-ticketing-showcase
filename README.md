# NoQis Support Desk: Project Showcase

A one-page visual summary of the NoQis Support Desk, the email-driven ticketing system for NoQis CDN support. Phases 0
to 3 (foundations, the ticket core, email, and SLA timers with on-call paging) are built. Phase 4, the agent console,
is underway: queues, the ticket view, the NoQis look with a light mode, the ticket panels, CDN providers, and type
and category filters and pickers are done.

Open `index.html` in a browser. It shows:

- The agent console: queues, a ticket page with its panels, light mode, and the new-ticket form (`screenshots/`)
- What happens when an agent saves a change, and how the audit hash chain links entries
- The rules the system enforces and where each one is tested
- Progress against the project roadmap
- How to run the app and a walkthrough checklist
- The decisions made so far

The application code lives in [noqis-ticketing-system](https://github.com/shensabo1/noqis-ticketing-system), a private
repository, merged through pull requests (52 so far). Last updated November 18, 2026.

All organizations, people, and tickets shown are invented sample data.
