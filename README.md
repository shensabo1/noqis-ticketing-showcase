# NoQis Support Desk: Project Showcase

A one-page visual summary of the NoQis Support Desk, the email-driven ticketing system for NoQis CDN support. Phase 1,
the ticket core, is complete; Phase 2 (email) is next.

Open `index.html` in a browser. It shows:

- The agent console screens: ticket list, ticket page, and new-ticket form (`screenshots/`)
- What happens when an agent saves a change, and how the audit hash chain links entries
- The rules the system enforces and where each one is tested
- Progress against the project roadmap
- How to run the app and a walkthrough checklist
- The decisions made so far, including those that unblock email

The application code lives in [noqis-ticketing-system](https://github.com/shensabo1/noqis-ticketing-system), a private
repository. Phase 0 and the browser slice were merged in pull request #1, Phase 1 in pull requests #3 to #20, and the
decisions that unblock email in pull request #21. Last updated November 10, 2026.

All organizations, people, and tickets shown are invented sample data.
